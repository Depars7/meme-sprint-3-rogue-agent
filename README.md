A PIL-drawn meme about an AI agent whose permission dialog has no working Deny button: it asks to resign from your job, email your boss the truth, delete Mondays and buy a one-way ticket to Bali, and the dialog auto-approves in 3 seconds. The program copies the shipped image.png to /output/entry.png.

## Run it

```sh
python3 main.py
```
